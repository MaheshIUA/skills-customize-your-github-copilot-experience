# 📘 Assignment: Problem Solving with Lists and Functions

## 🎯 Objective

Practice breaking larger problems into smaller function-based steps using Python. In this assignment, you will solve list-processing challenges by writing reusable functions with clear inputs and outputs.

## 📝 Tasks

### 🛠️ Build Core List Utility Functions

#### Description
Write small functions that each solve one focused task on a list of numbers.

#### Requirements
Completed program should:

- Implement a function to count how many values are even.
- Implement a function to return only values greater than a given threshold.
- Implement a function to return the largest value in a list.
- Use function parameters and return values instead of printing inside every function.
- Handle empty-list input for the largest-value function with a clear result or error message.


### 🛠️ Solve a Multi-Step Challenge with Function Composition

#### Description
Use your utility functions together in a short program that analyzes a class score list and prints a summary.

#### Requirements
Completed program should:

- Define a list of at least 10 integer scores.
- Compute and print: number of even scores, scores above a target, and highest score.
- Add one additional helper function of your choice (for example, average score or failing-score filter).
- Keep the program organized with meaningful function names and simple main-program flow.
- Produce readable output labels so another student can understand the results quickly.
